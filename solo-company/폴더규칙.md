# 작업 폴더 규칙

## 1. 폴더 구조

```
D:\회사\
├─ 01_숏폼편집\
│   ├─ [채널명]\
│   │   └─ 2026-11-24_영상제목\
│   │       ├─ 최종\        ← 최종본만 (mp4 등)
│   │       ├─ 썸네일\
│   │       ├─ 메모\        ← txt, 기획, 자막 원고
│   │       └─ 작업\        ← 원본 소스, 프로젝트 파일, 중간 렌더
├─ 02_에버웹\
├─ 03_홍보SNS\
├─ 04_웹개발_온티드\
├─ 05_미리캔버스\
├─ 06_본사\          ← 수익장부, 세금 서류, 계약서
└─ 99_보관\          ← 완료된 작업 (최종/썸네일/메모만)
```

폴더 이름은 `날짜_제목` 으로 시작하면 정렬이 쉽습니다.

## 2. 작업이 끝나면

1. 최종본은 `최종\`, 썸네일은 `썸네일\`, 메모는 `메모\` 에 넣기
2. `완료작업정리.ps1` 실행 → `작업\` 폴더 등 나머지는 `정리대기\` 로 이동
3. 일주일 동안 문제 없으면 `정리대기\` 를 외장하드/클라우드로 옮기거나 삭제
4. 남은 폴더는 `99_보관\` 으로 이동

## 3. 남기는 파일 (기본값)

| 종류 | 확장자 / 폴더 |
|---|---|
| 최종본 | `최종` 폴더, 또는 파일명에 `최종`/`final` 포함 |
| 썸네일 | `썸네일`/`thumb` 폴더, 또는 파일명에 포함 |
| 메모 | .txt .md .docx .hwp .pdf, `메모` 폴더 |

## 4. 컴퓨터 속도용 추가 청소 (가끔)

- 프리미어 미디어 캐시: 환경설정 → 미디어 캐시 → 삭제
- 캡컷/브루 캐시: 앱 설정의 캐시 지우기
- 윈도우: 설정 → 시스템 → 저장소 → 임시 파일 삭제
- 다운로드 폴더 비우기
