# 1인 회사 운영 세트 (오너용)

혼자 운영하는 사업 전체를 Claude 직원 9명에게 나눠 맡기는 세트입니다.

## 우리 회사 사업부

| 사업부 | 하는 일 | 담당 직원 |
|---|---|---|
| 숏폼 편집 | 여러 업체/방의 숏폼 편집 | 숏폼PD(총괄) + 업체별 전담 편집자 |
| 에버웹 | 홈페이지 제작 사업 준비 | 에버웹 사업기획 |
| 홍보 | SNS 게시물, 마케팅 | SNS마케터 |
| 웹 개발 | 홈피 제작 스킬 업그레이드, 온티드 홈피 리뉴얼 | 웹개발자 |
| 미리캔버스 | 기여자 콘텐츠 (SVG 포함) | 미리캔버스 디자이너 |
| 본사 | 수익·세금 / 스케줄 / 파일·저장공간 정리 | 경리 / 일정비서 / 파일정리 |
| 총괄 | 전체 업무 분배, 우선순위 | 비서실장 |

## 쓰는 법

### A. claude.ai 채팅 (무료도 가능, 폰에서도 됨)
1. claude.ai에서 **프로젝트**를 직원 수만큼 만들거나, 하나만 만들어도 됩니다.
2. `프롬프트모음.md`에서 직원 프롬프트를 복사해 **프로젝트 지침(Instructions)** 에 붙여넣습니다.
3. 그 프로젝트에서 대화하면 그 직원이 답합니다.

### B. Claude Code (이 저장소)
`.claude/agents/` 폴더에 직원 파일이 들어 있습니다. Claude Code에서
"비서실장한테 이번 주 일정 짜달라고 해" 처럼 말하면 해당 직원이 일합니다.

## 파일
- `프롬프트모음.md` — 채팅창에 붙여넣는 직원별 프롬프트
- `숏폼업체/` — 업체별 편집 가이드 (`_템플릿.md` 복사해서 업체마다 하나씩)
- `수익장부.csv` — 수익/지출 기록 양식 (엑셀·구글시트에서 열기)
- `폴더규칙.md` — 작업 폴더 구조와 완료 작업 정리 규칙
- `완료작업정리.ps1` — 끝난 작업 폴더를 자동 정리하는 윈도우 스크립트 (기본은 미리보기만)
